# FXバックテスト レポート生成

バックテストの取引結果を、利益額だけでなく**リスクと安定性**で評価した定型レポートにまとめる。
`performance-metrics` の考え方（「いくら儲けたか」より「どれだけのリスクで安定して儲けたか」）に従う。

## 入力

次のいずれか:
- `engine.run_backtest` が返す `trades_df`（`net_pnl` 列を持つ）
- それを書き出した CSV（最低 `net_pnl` 列、あれば `entry_time/exit_time/reason`）

## 手順

1. `net_pnl` 列を読み込む。空なら「取引なし（期間・パラメータを確認）」と報告して終了。
2. `metrics.py` で指標を計算する:

   ```bash
   python3 .claude/skills/fx-report/metrics.py <trades.csv> --account 300000
   ```

3. 出力を `template.md` の様式に流し込み、最後に採否コメントを付ける:
   - 期待値がプラスでない → 「採用しない（fx-project-rules）」
   - 勝率9割超・最大DDほぼ0・PFが極端に高い → 過学習の疑いを明記
   - ウォークフォワード結果があれば、検証期間でも安定して出ているかに触れる

## 指標の定義（metrics.py と一致させる）

- 勝率 = 勝ち取引 / 全取引
- 期待値(1取引) = net_pnl の平均
- プロフィットファクター = 総利益 / 総損失（損失0なら ∞ と表記）
- 最大ドローダウン = 累積エクイティ曲線の山からの最大下落幅
- 総損益(net) = net_pnl の合計（コスト込み）

## 注意

これは結果整理であって投資助言ではない。良い数字でも「なぜ儲かるのか」を説明できない戦略は採用しない。
